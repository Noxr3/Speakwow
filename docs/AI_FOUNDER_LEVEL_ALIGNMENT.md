# AI 创始人英语：难度定级与现有课程审查

2026-11-11 · 编辑性对齐草案，尚未完成实测定级。

## 结论

上一版 B1/B2 是教学目标标签，不能作为已经校准的等级。课程题目、创业资历、融资金额、词汇生僻程度或练习时长，都不足以决定 CEFR。应分别描述任务要求与学员在规定条件下的语言表现。

现有课程可作为分级改写的起点，但缺少稳定材料、锚定表现样本与人工评分校准。C1/C2 应在同一业务情境中提高语言要求，并保留熟悉业务背景；不能靠增加陌生商业知识来制造高级感。

## 官方依据与适用范围

核对了 Council of Europe 的 [CEFR Companion Volume 2020](https://rm.coe.int/common-european-framework-of-reference-for-languages-learning-teaching/16809ea0d4)：印刷页 76 的正式讨论、77 的任务协作、82–83 的书信、117 的分歧调解、141–142 的表达精度，以及 175 的等级说明。PDF 页索引比印刷页少 1。

关键边界：B2 已涉及专业讨论与论证；C1 强调灵活、连贯和自发应对；C2 更重细微意义、消歧与得体修复。部分量表的 C2 指向 C1，并非每项都另设更难一档。C2 不等于母语者身份或专业口译资格。

语言表现维度参考官方 [口语质量表](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)。任务说明参考 [ALTE/CoE 口语任务分析表入口](https://www.coe.int/en/web/common-european-framework-reference-languages/relating-examinations-to-the-cefr)。以下具体场景、数量、时间与路由规则是 Speakwow 的设计方案，不是官方分数线。

## 用同一任务区分 B1–C2

以“客户认为价格太高”为共同任务。所有级别都可遇到这句话；差别在输入、回应与互动要求。

| 设计目标 | 给学员什么 | 期待学员做到什么 | 本课不能据此判级的表现 |
|---|---|---|---|
| B1 | 已解释的产品、明确价格与一项直接异议；清楚表达，可请求重述 | 澄清对方比较什么，给一个理由，讨论简单下一步 | 背出一句折扣话术 |
| B2 | 熟悉行业中的两种方案和相互关联的约束；正常往返追问 | 比较取舍、回应反对理由、修正建议并总结条件 | 只报出正确价格或完成销售 |
| C1 | 买方、使用者、预算方的不同立场；部分理由未直接展开 | 整理不同论点，自发追问和改述，精确限定承诺，组织有逻辑的建议 | 只增加更长的演讲或更多术语 |
| C2 | 同一证据集下出现歧义、立场变化与敏感分歧 | 保留细微差别，检查可能的含义，化解歧义，改变表达策略并维持关系 | 武断猜测“真实心理”、刻意炫耀习语、模仿口音 |

这些是目标任务规格，不声称四道题即可测出全球通用语言等级。正确的商务结论可能有多个；选择不合作仍可展现高水平英语。

## 每项任务必须写清的八项规格

1. **主要能力**：例如口语互动、论证、阅读、书信或调解；引用量表名称与页码。
2. **业务前提**：学员已经知道什么；陌生术语先在任务外解释，避免把知识缺口算成语言缺口。
3. **输入条件**：内容是明确还是含蓄、材料间是否冲突、允许重听重读什么。
4. **输出要求**：要完成的语言行为，以及必须保留的事实、条件与语气。
5. **互动条件**：谁与谁说话、是否有追问、是否需调节语域；同一老师轮流扮演时需说明换角色。
6. **帮助边界**：练习可示范；检查可解释任务要求或重复原话，不能提供答案框架再记成独立表现。
7. **评价证据**：学员实际说/写了什么，在哪些回合体现目标，是否需要帮助。
8. **等值变体**：换人物、数据或约束时保留目标能力与负荷；不能随意把重测题变难。

每课课节不是都要达到该级上限。词卡、跟读、短听写可以是较低难度的准备活动；等级依据应来自独立、连贯、有迁移要求的表现，不能因这些微练习正确就推断 C1/C2。

## 对已写 B1/B2 的逐单元审查

以下均为内容审读判断，不是学生表现数据。“可保留”指在限定条件下可作为目标级训练，不能理解为已通过实证校准。

| 单元 | 审读结果 | 修订要求 |
|---|---|---|
| B1-01 产品解释 | 可保留 | 熟悉产品、直白提问；术语替换是准备活动，独立说明才是证据 |
| B1-02 客户访谈 | 可保留 | 具体过去事件；一次追问一个要点，不要求识破隐含动机 |
| B1-03 痛点影响 | 可保留 | 清楚数字与单位；听写只证明所测信息和书写，不代表整体听力 |
| B1-04 Demo | 可保留 | 熟悉流程与可预期问题；不要求应对技术故障或主持复杂辩论 |
| B1-05 客户综合 | 原任务条件不足 | 事先说明事实与角色，限制为常规需求交流；不加隐藏采购政治 |
| B1-06 创始人故事 | 可保留 | 真实或明确虚构的熟悉经历；简洁因果，不要求文学叙事 |
| B1-07 数据 | 可能混入专业知识 | 先教口径，使用小型记录；不把财务知识作为语言难度 |
| B1-08 融资用途 | 边界偏松 | 说明已给定的行动与里程碑；不要求设计财务方案 |
| B1-09 投资人问答 | 边界偏松 | 限制可预期问题、直白追问；策略性或连环反驳留到后级 |
| B1-10 融资综合 | 原任务条件不足 | 小型一致资料；允许澄清问题，不测试陌生市场或复杂估值 |
| B1-11 社交开场 | 部分活动低于 B1 | 识图是热身；考核连贯问答、相关性与自然结束 |
| B1-12 合作提案 | 可保留 | 清楚的双方分工；不要求隐含利益调解 |
| B1-13 试点 | 可能混入专业知识 | 给定验收概念与方案，让学员解释范围与简单取舍 |
| B1-14 更新 | 可保留 | 常规事实、阻塞与请求；不要求复杂声誉危机回应 |
| B1-15 合作综合 | 边界偏松 | 一个清楚变动，具体可讨论的方案；避免多方谈判负荷 |
| B2-01 买方决策 | 可保留但限定材料 | 立场来自明确背景卡；不要求准确猜测隐藏权力关系 |
| B2-02 AI 限制 | 可保留 | 解释有证据的条件；微跟读不能单独证明 B2 |
| B2-03 定价试点 | 可保留 | 比较给定选项与理由，不自行推导未知成本模型 |
| B2-04 已有 AI 方案 | 可保留 | 熟悉领域、可明确的异议；不要因出现 ChatGPT 就认定高级 |
| B2-05 客户综合 | 需要稳定条件 | 关联约束但不连续追加新背景；给可比较的事实 |
| B2-06 切入口 | 可保留 | 用理由支持立场；不把“战略叙事”自动升级到 C1 |
| B2-07 增长质量 | 可能知识负荷过高 | 解释口径并控制表格复杂度；不能凭读表正确判 B2 |
| B2-08 尽调 | 可保留 | 处理给定矛盾与缺失；不要求法律或会计判断 |
| B2-09 融资选择 | 可保留 | 表达条件取舍，答案不必符合某家 VC 偏好 |
| B2-10 融资综合 | 需要稳定条件 | 根据已知材料论证，追问围绕同一问题；不以压迫感定级 |
| B2-11 社交合作 | 热身过易 | 简单识图不能当 B2 门槛；需要回应不同优先级并协商下一步 |
| B2-12 范围重谈 | 可保留 | 明确约束下比较方案；复杂多方隐含冲突留到 C 级任务 |
| B2-13 失败恢复 | 可保留 | 熟悉客户交流、事实与假设分开；危机级外交措辞不是硬要求 |
| B2-14 战略更新 | 原表述可能越界 | 限定为提出建议、回应直接挑战；综合多方复杂立场单列 C1 |
| B2-15 合作综合 | 原任务叠加偏多 | 先读清事实再逐步讨论；不同时制造身份、法律、时间多重压力 |

本次将这些条件写入单元 points，确保当前教师上下文能读取；细化 B1/B2 综合考核和 B2-14 的提示。保留既有目标 ID 和进度含义，不把同一个 ID 改造成另一项能力。

## 语言与创业判断分别评价

语言证据按理解与回应、表达连贯、词语和句法控制、语域与精度整理；创业任务另看证据使用、假设区分和可执行下一步。课程可教两者，但不能把商业判断评分合成 CEFR 水平。一个创业老手的商业答案可能很好，语言仍需要基础练习；反之亦然。

口语、阅读、写作也应分别记录。例如“熟悉客户任务中的口语互动接近 B2，书面跟进仍需 B1 支持”，比给整个用户一个整数等级更有教学价值。资料不足时标“未观察”，不能用缺测作零分。

目前运行时的 0.8 是课节目标推进规则，未与 CEFR 锚定；它不等于 B2、80% 熟练度或证书通过线。本次仅改课程内容，未实现新的分技能评分数据库或自动分级服务。

语速快、口音像母语者、填充词少、回答长，都不能单独作判据。口音不影响理解时不作晋级障碍；转录无法提供细粒度语音或重音证据。课程的朗读、听写和对话支持不等于完成全面听力测验。

## 初始诊断与校准方案

先确认业务背景，再做熟悉产品解释、追问与澄清、给定材料下的方案比较，以及短书面跟进。起始可从 B1/B2 交界观察；表现稳定才给更复杂语言要求，困难时降低负荷。不要把第一轮的紧张直接判成低级别。

建议跨两个独立任务观察同一能力，再于另一节复核；这是产品试验规则，不是官方切分标准。用户可选择更基础或更有挑战的训练；课程推荐和学员能力判断分别展示。C1/C2 的推荐应保留不确定性，不能靠一次背熟的 pitch 升级。

正式对齐需要建立可追溯证据链：熟悉量表、编写任务规格、训练评分者、选定锚定表现、设置边界并持续验证。这遵循 [CoE 定级手册](https://rm.coe.int/CoERMPublicCommonSearchServices/DisplayDCTMContent?documentId=0900001680667a2d) 的方法方向，不代表本项目已完成这些步骤。

后续试点应包含独立双评、边界样本与分歧仲裁；比较跨题一致性、不同口音和业务熟悉度的影响、提示前后表现及重测变化。小样本先修任务，不能据少数试课直接宣布等级精确。AI 评分与人工结论的一致性需另外验证。

## C1/C2 编写门槛

所有新单元注明目标量表、语言要求与不能证明等级的微练习。C1 检查论证组织、灵活改述和限定表达；C2 加强歧义修复、细微立场与敏感互动，不能把所有能力项强行升一档。

场景仍围绕客户、融资、合作。C2 学员也可以是刚开始创业的人；应提供足够业务背景，不能要求先掌握并购、证券、法律或董事会经验。课程提供语言任务设计，不作执业能力判断。
