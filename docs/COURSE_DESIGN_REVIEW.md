# Course design review · 2026-11-10

结论：家庭教师、真实任务、允许短暂发散、分开练习与测评的方向可以保留。当前版本是可运行的课程设计草案，尚不是经过学生学习效果验证的完整课程产品。主要缺口在目标负荷、延迟复习、材料稳定性与测评效度，不能用 96 节课的数量或游戏参与度替代效果证据。

## 范围与证据

本次检查了课程格式、导入器、教师上下文、课时推进和评分路径；统计了全部目录。英语部分包括 8 个技能系列（40 单元、104 个显式 Session）、译林七上（8 单元、96 个显式 Session），以及另外 3 册译林提纲（24 单元，使用默认 Session）。融资课程不在本次英语教学评审范围。统计不等于每个动态生成材料都已逐题审阅。

研究采用教育机构指南、语言教学框架、原始实验和课堂研究综述。对每条证据区分“研究观察到什么”和“我们如何应用”；未把大学生实验结果直接当作七年级 AI 家教的效果保证。

## 按优先级列出的发现

| 优先级 | 发现与实际影响 | 本次处理 | 仍需验证 |
|---|---|---|---|
| P1 | 七上导入课引用全部 5–6 个原目标；10 分钟复习引用 9–10 个目标。系统要求本节每个目标都达到 0.8 才推进，可能尚未教学就卡住。 | 将导入与复习各收窄到 2 个核心目标；完整目标仍由后续练习和单元测评覆盖。 | 试课观察每节耗时、重复失败和教师是否提前要求未教技能。 |
| P1 | 综合课 `activity=mixed` 包含 writing 目标，但原来的打字检查仅按活动类型，口头答复可能进入写作评分。 | 进度流程与保存入口同时按本节目标检查：涉及 writing 必须有标记为打字的回答。新增失败复现和回归测试。 | 这保证证据存在，不保证草稿质量、作者独立性或评分模型校准。 |
| P1 | 语音目标由文本反思评分链路处理；文本不能可靠证明音位、重音和节奏准确度。 | 保留作为教学练习，明确不宣称声学精度或标准化语音诊断；在试课清单中单列。 | 后续需要音频证据或经校验的教师观察，并比较人工评价；不能靠模型给出小数来解决。 |
| P2 | 复习集中在单元末，“下次复习”没有具体落点。 | 在第 4、6、10 节加入旧表达提取，要求下次见面与后续单元再次使用；先提取后提示。 | 当前没有按日期调度的间隔重复系统；是否真的跨日复现需要课堂记录。 |
| P2 | 每次都增加新情境，熟悉内容的流利表达时间不足。 | 迁移课增加用熟悉词语再次讲述，并把轻微纠错延后到讲完。 | 重述之后还需新情境任务，避免只练熟一个脚本。 |
| P2 | 阅读难度主要按字数递增，不能控制未知词、句法或推断距离。 | 加入以熟悉词为主、仅解释少量必要新词、主旨不清时缩短句子等材料规则。 | 需要固定样本和人工抽检；字数与 Pre-A1/A1/A2 标签都不能单独保证适配。 |
| P2 | 12 节固定顺序仍偏“活动目录”；即使已会也要逐节留下证据。 | 保留单元终局作品，支持课内降低或提高支架。 | 自动分支、免修和补救路径需要新产品能力；本次没有宣称已经自适应跳课。 |
| P2 | 4 种通用插画反复使用，部分校园或节庆任务依赖想象。 | 所有已写入的看图任务区分可见、推断、想象。 | 后续补齐原创校园、人物、节庆、预算图，图片必须与任务版本绑定。 |
| P2 | 阅读与考试材料由模型现场生成，跨学生难度和答案一致性不稳定。 | 明确题型、信息数量、长度范围、原创要求和证据形式。 | 应建设版本化材料包、答案依据和等值重测题；schema 校验无法代替内容校验。 |

## 研究依据与设计判断

### 1. 从真实任务反推学习目标

欧洲委员会的行动导向框架强调有意义的沟通实践和学习者能动性。它支持把“为同学组织活动”作为整合任务，而不是只按卡片类型排列练习。这是框架依据，并非本产品学习效果的实验验证。[Council of Europe：Action-orientation in the classroom](https://www.coe.int/en/web/common-european-framework-reference-languages/action-orientation-in-the-classroom)

对应判断：每单元先确定最终作品和交往目的，再安排词汇、输入、练习与独立迁移。让学生选择社团、菜单和话题；评分看其是否表达清楚和处理约束，不判断兴趣或审美的对错。七上的“校园庆祝活动”可以保留，但各单元必须也能独立成立。

### 2. 提取、间隔与支架撤除

IES 指南建议分散学习、交替示范与独立解题、用提取练习再次接触内容，并提出解释性问题。指南对这些建议的证据强度并不相同：间隔与示范交替为 moderate，提取再接触与解释性提问为 strong；不是所有建议都有同等强度。[IES：Organizing Instruction and Study to Improve Student Learning，2007](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)

对应判断：先试着回忆，再给提示，完成后在新任务里使用；数天后和后续单元再出现。第 4、6、10 节是本项目的排课选择，不是研究证明的最佳间隔。示范一次、共同完成、撤掉提示的顺序适合保留；已经会的学生应减少示范。

### 3. 游戏体验和学会是两个指标

James 与 Mayer 的实验让 64 名大学生学习意大利语，比较 7 次 Duolingo 学习与同材料幻灯片学习。游戏组对体验和继续学习的意愿评价更积极，但两组后测成绩未出现显著差异。它提示我们分别测参与意愿和学习结果，不能解释为所有游戏都无效，也不能外推为七年级学习效果。[James & Mayer，Learning a second language by playing a game，2019](https://onlinelibrary.wiley.com/doi/10.1002/acp.3492)

对应判断：预算、找线索、扮演记者等机制直接需要目标语言；答对卡片之后要解释、问问题、换角色或迁移。默认不加速度排名、扣血或强制连胜。2–3 分钟游戏长度属于本产品的节奏假设，需要观察，不是研究给出的阈值。

### 4. 纠错应促成学生自己的修正

Lyster 与 Saito 的课堂研究元分析纳入 15 项研究、827 名学习者，发现口头纠错对目标语言发展有持续作用，提示学生修正的效果总体上大于直接重述正确表达。实际效果受课堂与测量条件影响，不能推出任何一次提示都优于示范。[Lyster & Saito，Oral Feedback in Classroom SLA，2010](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/abs/oral-feedback-in-classroom-sla/4999EE1C8379B2BF026B148EAF373CA1)

对应判断：练习时先提示一次让学生自己修正；卡住再给短示范。表达流利度片段先听完，再挑一个重点反馈。正式检查中不边提示边计为独立完成。这里采用的是可执行的课堂策略，不声称研究直接比较过 Speakwow 的 AI 对话。

## 下一轮课堂验证

先用第 1、4、7 单元做小范围试课，覆盖入门、跨单元整合和带约束的协商。选择不同基础、不同输入习惯的学习者，观察任务，不把满意度问卷当作学习测试。正式开展未成年人试课前另行安排适当的参与同意与数据流程，本次没有招募或联系学生。

建议记录：任务完成情况、独立表达、提示次数、识别错误、实际耗时、重复卡关点、学生主动提问、休息后的返回情况。游戏增加点击但降低独立表达时，应删减或改写，而非继续加奖励。

同一目标至少比较当节无提示任务、后续会话的新情境任务，以及约一周后的延迟提取。时间点是试课方案选择，不是自动调度功能。用同等难度的新题，避免重用答案记忆；学习日志只保存完成这项评价所需的信息。

研究报告与代码检查不能替代上述验证。后续优先级是稳定材料与评分证据、补救/免修路径、按日期复习，再考虑更多游戏视觉组件。
