# courses/

Course outlines the teacher can teach unit by unit. Import one with
`pnpm course:import packages/shared/courses/<slug>.json` (or keep the units in a
Dokki table and add `--from-dokki <tableId>`).

| File | Course |
|---|---|
| `yilin-2024-7a.json` | 译林版初中英语 七年级上册（新课标，2024 秋起用） |
| `yilin-2024-7b.json` | 译林版初中英语 七年级下册（2025 春起用） |
| `yilin-2025-8a.json` | 译林版初中英语 八年级上册（2025 秋起用） |

**How these were made (2026-10):** unit titles and grammar points were
cross-checked across at least two independent teaching sites for 31 of 32
units (8A Unit 5's grammar has one source). No publisher page was available, so
please check against a printed copy or the teacher's book and open a PR for any
difference. Theme categories are our own classification against the 2022
standard. Functions and word lists are summaries; speaking tasks are original.

**Copyright:** outlines only. Never add reading passages, dialogues or
exercises from a textbook.
