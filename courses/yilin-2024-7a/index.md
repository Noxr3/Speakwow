# 译林版初中英语 七年级上册（7A，新课标）

这是一套面向七年级学习者的家庭教师课程。学习主线是“和新朋友一起筹备校园庆祝活动”：先认识彼此，再选择社团、认识校园、安排时间，最后把饮食、穿搭和预算组合成一次真实的沟通任务。

全册 **8 单元、96 节课，建议教学时间约 24 小时 50 分钟**，不含自由聊天和休息。每节约 10–30 分钟，也可以分几次完成。难度按“有支架完成 → 独立表达 → 解释与迁移”递进，不把七年级或原表中的标签直接换算成 CEFR 认证等级。

每个单元有词汇导入、语音猜词、听写、两节阅读、两节写作、看图表达、两节情景互动、复习和独立测评。第 4、8 单元分别以迎新日和校园节庆作整合任务。短小游戏穿插在练习中，学生可以跳过；不会为了积分、计时或固定轮数打断对话。
